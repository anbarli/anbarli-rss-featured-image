# Security Policy

## Supported Versions

The current `1.x` release line receives security fixes.

## Reporting a Vulnerability

Please report security issues privately by contacting the maintainer through the repository owner profile or website.

Do not open a public issue for vulnerabilities that could expose sites or users.

## Scope

This plugin only writes RSS XML output for post featured images. Security reports are most useful when they include:

- WordPress version
- PHP version
- Steps to reproduce
- Expected and actual output
- Any proof of concept that demonstrates the issue
