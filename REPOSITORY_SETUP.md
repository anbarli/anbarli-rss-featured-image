# Repository Setup Checklist

Use this checklist after pushing the repository to GitHub.

## About

Recommended GitHub About description:

```text
Add WordPress featured images to RSS feeds as Media RSS media:content tags for readers, aggregators, and newsletter workflows.
```

Recommended website/demo link:

```text
https://anbarli.com.tr
```

If you publish a demo feed or documentation page, use that URL instead.

## Release

Create the first release:

```text
Tag: v1.0.0
Title: Anbarli RSS Featured Image 1.0.0
```

Suggested release notes:

```md
Initial release of Anbarli RSS Featured Image.

- Adds WordPress featured images to RSS feeds as Media RSS `media:content`.
- Adds the Media RSS namespace automatically.
- Supports configurable image size via `anbarli_rss_image_size`.
- Supports optional RSS enclosure output via `anbarli_rss_add_enclosure`.
```

## Good First Issues

Create these starter issues:

- Add PHPCS configuration for WordPress coding standards.
- Add automated tests for RSS output.
- Add compatibility notes for Mailchimp RSS campaigns.
- Add compatibility notes for Feedly.
- Add a WordPress.org assets folder with banner and icon.
- Add a Docker Compose local WordPress test environment.
